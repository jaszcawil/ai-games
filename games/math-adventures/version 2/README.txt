========================================================================
 MATH ADVENTURES with Wonderblocks and Noodle and Pals
========================================================================

A 3D adventure game for grade-school math (place value, addition,
subtraction, multiplication, division, and order of operations).

Play as Again, Stop, Blossom, or Red! Set out from your home base and
travel, one continuous world, to each of the five villages to meet its
Math Chief (Tiffany, Grey, Nayah, Naomi, Carmela). Each village has 5
obby-and-puzzle challenges in a row -- clear all 5 (answering a math
question at each one) to earn that chief's badge. Once you've earned
all 5 badges, the path to the Math Master, Jasz, opens for the Final
Gauntlet.

Your home base has an Achievement Board that lights up with a star for
every badge you've earned, so you can always see your progress at a
glance.

------------------------------------------------------------------------
 HOW TO RUN IT (do this first)
------------------------------------------------------------------------
Web games like this need to be served over http:// -- double-clicking
index.html directly won't load the 3D models or let you save. Pick
whichever option below is easiest for you:

  OPTION A -- Play on THIS computer only (easiest)
    1. Install Node.js if you don't already have it: https://nodejs.org
       (choose the LTS version, keep every installer option default)
    2. Double-click "run.bat" in this folder.
    3. A black window will open and print a web address -- your
       browser should open automatically. If not, open the address
       it shows (something like http://localhost:8080) in Chrome,
       Edge, or Firefox.
    4. Leave that black window open while you play. Closing it stops
       the game server.

  OPTION B -- Play on your PHONE/TABLET too (same WiFi)
    Same as Option A, but the black window also prints a second
    address like "http://192.168.1.23:8080" -- open THAT address in
    your phone or tablet's browser while it's on the same WiFi network
    as your computer.

  OPTION C -- Play truly ONLINE (from anywhere, shareable link)
    Upload this whole folder to any free static web host, for example:
      - https://app.netlify.com/drop  (drag-and-drop this folder, done)
      - Vercel, GitHub Pages, itch.io (HTML5 project), or any web host
    Once uploaded, the site's URL is a shareable link that works from
    any device, anywhere, no server needed on your end.

------------------------------------------------------------------------
 CONTROLS
------------------------------------------------------------------------
  Mobile / Tablet / Touch:
    - Left joystick  = move
    - JUMP button    = jump
    - Sparkle button = hero's special power
    - Drag anywhere else on screen = look around / orbit the camera
    - Pinch = zoom camera in/out

  PC / Keyboard:
    - WASD or Arrow Keys = move
    - Space   = jump
    - Shift or E = special power
    - Mouse drag on the game = look around / orbit the camera
    - Mouse wheel = zoom
    - R = recenter camera, Q/E = nudge camera left/right
    - Esc or P = pause

  Game Controller (Xbox/PlayStation/etc, connected via USB or
  Bluetooth): left stick = move, A = jump, X = special power,
  Start = pause. Just connect it and press any button to activate it.

------------------------------------------------------------------------
 SAVING YOUR GAME
------------------------------------------------------------------------
The game autosaves your progress in the browser automatically. You can
also, from the Pause menu:
  - "Save Game"            -- saves to this browser (like autosave)
  - "Save to Device File"  -- downloads a .json save file you can keep
                               anywhere (a USB drive, cloud storage,
                               email to yourself, etc.)
  - "Load From File"       -- loads a previously downloaded save file,
                               on ANY device/browser, so you can
                               continue your adventure anywhere.
